# 需求真实性与 Amazon 机会分析实施计划

## 目标

在现有 Google Trends 工作台中增加趋势真实性判断、地区稳定性分析、Amazon 关键词 CSV 导入与机会匹配，并提供 3 天/7 天更新计划和可选的 OpenAI 兼容 AI 分析。

## 交付范围

1. 后端使用可解释规则计算长期/近期均值、斜率、波动、峰值持续时间和地区集中度。
2. 使用标准库解析带 BOM 的 Amazon CSV，支持中英文关键词列和常见搜索量、排名字段。
3. 将 Google 上升率、长尾程度、Amazon 竞争信号和文本相似度合成为 0–100 机会分数。
4. SQLite 保存导入关键词、趋势快照、计划和执行状态；计划周期限制为 3 天或 7 天。
5. 无 AI 配置时返回规则分析；配置 OpenAI 兼容端点后补充结构化模型意见。
6. 页面增加机会分析视图、CSV 上传、真实性卡片、机会表和计划设置。

## 验证

- 单元测试覆盖短期爆发、持续趋势、噪音、数据不足、地区集中、CSV BOM/中文列、非法数字、匹配排序和计划周期。
- 运行 pytest、Node 前端测试、ruff、uv lock 检查，并使用浏览器完成 CSV 导入与机会分析流程。
