# Google Trends 搜索趋势工作台

## 目标与范围

把已调研的 trendspyg 封装为可在本机运行的中文网页应用。面向关键词研究与内容选题：比较搜索兴趣、发现热搜、保存研究条件、导出结果、跳转 Google 搜索和 Google Trends。首版为单用户本地应用，不含账户、云部署、付费数据源和无人值守提醒。

## 方案选择

1. 仅提供命令行：实现简单，但不便对比和探索。
2. Python 服务与轻量网页界面（采用）：直接复用 trendspyg，同一服务提供页面和数据接口，无前端构建步骤。
3. 完整前后端框架：更适合大型团队，当前增加安装和维护成本。

## 功能与数据边界

- 趋势探索：1–5 个关键词，国家或全球范围、时间和搜索类型筛选；同一量纲曲线、平均兴趣、峰值、相关查询和地区分布。
- 实时热搜：按国家获取 RSS 热点和新闻，支持将词加入探索。
- 本地收藏：保存关键词与筛选条件，刷新后保留，可恢复或删除。
- 导出：当前结果 CSV，中文可读，并防止电子表格公式注入。
- 外链：正确编码关键词与筛选条件，打开 Google Trends 或 Google 搜索。
- 演示模式：明确标注合成数据，便于首次体验和离线验证。任何真实数据失败均不得静默替换成演示数据。
- 搜索兴趣为 0–100 相对指数，不代表绝对搜索次数；多词对比必须来自一次共同归一化的请求。

## 架构与交互

FastAPI 提供静态页面与 JSON API。纯 JavaScript 管理视图和 SVG 图表，支持键盘操作与移动端布局。中文界面使用深色窄侧栏、浅色内容区与青绿色主色。后端将 trendspyg 输出转为稳定的内部结构，真实查询进入独立进程，避免浏览器操作阻塞服务；限时结束进程树，限制并发、缓存成功结果。仅监听 127.0.0.1。

页面包含趋势探索、实时热搜、我的收藏。每张图与导出文件保留数据模式和请求条件；异步响应只更新其所属查询，编辑或切换筛选不会错误标注旧结果。

## 失败与安全

校验关键词数、长度、地区、时间和类型。网络错误、429、超时、Chrome 缺失、空结果分别给出可行动的中文反馈。数据以文本节点插入，外链仅接受 HTTP(S)，新闻外链使用 noopener。拒绝任意来源的跨站 API 请求，不接受用户传入上游 URL。

## 验收

离线测试覆盖输入校验、上游结构适配、缓存与错误、CSV 公式安全和结果身份。实测 RSS；用浏览器检查桌面和手机布局、查询、模式切换、收藏、外链、导出。真实关键词查询若被限流，记录实际失败，保留可用的明确错误反馈。
