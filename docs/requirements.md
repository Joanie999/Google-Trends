# 产品需求与任务清单

## 用户与场景

为内容研究、产品选题和关键词观察提供本地中文工作台。用户从候选关键词或地区热搜出发，比较相对兴趣，查看地区和相关词，保存研究条件并导出结果。

## 首版验收任务

- [x] 1–5 词输入、去重与长度校验。
- [x] 14 种地区范围（含全球）、5 种时间范围、5 种搜索类型。
- [x] 单词和多词真实趋势获取，多词共用归一化量纲。
- [x] 趋势图、鼠标提示、键盘浏览与完整数据表。
- [x] 平均兴趣、峰值与最近两个四点窗口的均值变化，排除未完整时间点。
- [x] 单词相关搜索及地区排行，多词相关搜索显示能力边界。
- [x] 真实 RSS 热搜、关联新闻和关键词探索入口。
- [x] 保存、恢复、删除本地查询收藏。
- [x] CSV 导出、公式防护、Google 搜索和 Trends 外链编码。
- [x] 显式演示模式，以及真实请求失败、无数据、冷却、加载反馈。
- [x] 缓存、并发限制、进程超时清理及本机访问约束。
- [x] Windows 启动脚本、依赖锁、使用说明和 API 文档。

## 交付边界

本版只在本机运行，不包含远程部署和 GitHub 发布。收藏仍保存在浏览器；Amazon 关键词、真实趋势快照和 3 天/7 天更新计划使用本地 SQLite。后台计划器默认关闭，避免服务启动时意外访问 Google；设置 `TRENDSCOPE_SCHEDULER=1` 可开启本地守护线程。没有多用户身份认证。

## 第二阶段验收

- [x] 需求真实性规则：持续趋势、短期爆发、噪音、稳定、数据不足及证据/置信度。
- [x] 地区覆盖率、最高地区份额、前五地区份额和局部集中判断。
- [x] Amazon CSV 导入：BOM、中文列名、搜索量/排名/竞争度/ASIN 可选字段和非法数字警告。
- [x] Google 上升长尾词匹配 Amazon 关键词，输出匹配类型、相似度和机会分数。
- [x] 3 天/7 天更新计划、历史快照和本地 SQLite 存储。
- [x] 可选 OpenAI 兼容 AI 分析；无密钥时规则分析仍可用。

## 成功标准

首次启动可体验演示模式；网络与 Chrome 正常时可获得真实热搜和关键词数据。任何失败均有明确反馈，不以虚构数据替代真实结果。桌面与手机可完成查询、收藏与导出。
