# 第二阶段需求：需求真实性与 Amazon 关键词联动

## 验收标准

- 趋势结果显示持续趋势、短期爆发、噪音、稳定或数据不足，并给出证据和置信度。
- 地区结果显示跨地区或局部集中，展示覆盖率、最高地区份额和前五地区份额。
- 可以导入 Amazon 关键词 CSV。关键词列支持 `keyword`、`关键词`、`search term`、`term`；搜索量、排名、竞争度和 ASIN 为可选字段。
- 机会匹配同时支持精确、词元和相似匹配，结果包含 Google 上升率、Amazon 信号、相似度和机会分数。
- 更新计划只允许每 3 天或每 7 天一次，保存最近执行状态；真实抓取失败不生成趋势快照。
- 未配置 AI 时规则分析可用；配置 OpenAI 兼容环境变量后可以请求结构化 AI 结论。
